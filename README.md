# DRMリンク拾いツール

経路を地図上で指定し、通過する DRM リンク・ノード番号を Excel に出力する社内ツール。
配布場所（全国共有フォルダ）：`\zlcb005\09_横連携【一時保存】\00_部門共通\04.全国情報共有フォルダ\20_DRM拾いツール\10_リンク拾いツール`

## 絶対に守ること
- **DRM・JTMA 等のデータは GitHub に上げない。** `.gitignore` で `_cache/`・`_利用ログ/`・`*.json`・`*.csv`・`*.xlsx` 等を除外済み。消したり緩めたりしない。
- SQL Server（JARTIC・トラカン）へのアクセスは読み取りのみ。

## 構成
| ファイル | 内容 |
|---|---|
| `起動.bat` | 利用者が実行。本体をローカル（`%LOCALAPPDATA%\DRMリンク拾いツール`）にコピーして起動 |
| `30_ツール本体（触らない）/server.py` | Python 標準ライブラリのみの HTTP サーバー（経路探索・Excel出力等） |
| `30_ツール本体（触らない）/index.html` | 画面（Leaflet） |
| `jartic.py` / `torakan.py` | JARTIC・トラカン地点データの作成（`--update-jartic` / `--update-torakan`） |
| `usage.py` | 利用ログ |
| `20_使い方と出力ルール（見なくても良い）.txt` | 利用者向け説明書 |

## 開発のしかた
1. 自分の PC に clone する（共有フォルダ上で直接作業しない）
2. ブランチを切って修正する
3. 動作確認：DRM データと変換済みキャッシュは共有フォルダのものを参照して起動
   ```
   python -X utf8 "30_ツール本体（触らない）\server.py" "\zlcb005\...\20_DRM拾いツール\DRMコピー_こっちを使う" --shared-cache="\zlcb005\...\10_リンク拾いツール\30_ツール本体（触らない）\_cache" --port=8766 --no-usage
   ```
   （`--port` は利用者の 8765 と被らない番号に。`--no-usage` で利用ログに記録しない）
4. GitHub に push して Pull Request を作り、もう一人が確認してから `main` に取り込む

## 全国への反映
共有フォルダ（配布場所）で `git pull` する。`main` に入ったものだけが全国に出る。
利用者は次回 `起動.bat` を実行したときに新しい版になる（画面は Ctrl+F5 で更新）。
